## 📖 Full Description

### ⚡ The Only Cross-Platform GPU IDE — CUDA + Metal + OpenCL + Vulkan in One Plugin

**The Problem:** GPU development is fragmented. CUDA developers are stuck with aging Nsight Eclipse (2019). Metal developers can't leave Xcode. OpenCL has no first-class IDE support anywhere. Switching between GPU frameworks means switching between tools, losing productivity and context.

**The Solution:** GPU Dev Accelerator Ultimate brings comprehensive GPU development to JetBrains IDEs — syntax highlighting, intelligent code completion, integrated debugging via cuda-gdb, real-time profiling with flame graphs, and AI-powered kernel optimization. One plugin, all major GPU frameworks.

---

### ✨ Key Features

#### 🎨 Multi-Framework Language Support
- **CUDA** (`.cu`, `.cuh`) — Full C/C++ syntax highlighting, code completion, compilation
- **Metal** (`.metal`) — Shading Language support, Metal Performance Shaders
- **OpenCL** (`.cl`) — C syntax, cross-vendor support (NVIDIA, AMD, Intel)
- **Coming soon:** Vulkan Compute, SYCL, ROCm/HIP

#### 🐛 Advanced CUDA Debugging (Individual/Enterprise)
- Full **cuda-gdb** integration with breakpoint support
- Thread inspection and warp-level stepping
- Memory watchpoints for GPU memory
- Keyboard shortcut: `Ctrl+Shift+Alt+D`

#### 📊 Real-Time Profiling with Flame Graphs (Individual/Enterprise)
- **nvprof** and **Nsight Compute** integration
- Occupancy and bandwidth metrics visualization
- GPU kernel flame graphs for performance analysis
- Keyboard shortcut: `Ctrl+Alt+P`

#### 🤖 AI-Powered Kernel Optimization (Individual/Enterprise)
- **Memory coalescing** suggestions (up to 2.5× speedup)
- **Bank conflict** detection (up to 1.3× speedup)
- **Warp divergence** analysis (up to 1.8× speedup)
- Keyboard shortcut: `Ctrl+Alt+O`

#### 🖥️ Multi-GPU Topology Visualization (Individual/Enterprise)
- Auto-detect GPU topology across the system
- Real-time utilization and temperature monitoring
- Keyboard shortcut: `Ctrl+Alt+G`

#### 🧠 Advanced Memory Analysis (Individual/Enterprise)
- Memory leak detection for GPU allocations
- Race condition detection across threads
- Allocation tracking and lifetime visualization
- Keyboard shortcut: `Ctrl+Alt+M`

### 🚀 Quick Start

1. **Install** the plugin from JetBrains Marketplace
2. **Create or open** a project with `.cu`, `.metal`, or `.cl` files
3. Enjoy **syntax highlighting and code completion** immediately
4. For CUDA debugging: ensure `cuda-gdb` is installed and press `Ctrl+Shift+Alt+D`
5. For profiling: press `Ctrl+Alt+P` to launch the profiler tool window
6. Explore AI optimization suggestions with `Ctrl+Alt+O`
