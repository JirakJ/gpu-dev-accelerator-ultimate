## Short description

> CUDA, Metal and OpenCL support for IntelliJ-based IDEs: highlighting, completion and quick docs, nvcc
> compilation with clickable errors, PTX view, compute-sanitizer and Nsight Compute runs, GPU topology,
> kernel heuristics, an occupancy calculator and kernel port starting points.

## Full description

The plugin's description is maintained in `src/main/resources/META-INF/plugin.xml` and mirrors the
[README](README.md) feature list. Keep the three in sync and list only what the plugin actually does —
there is no debugger integration, no Vulkan support and no AI component.
